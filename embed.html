Code to copy

Option 1: Script (recommended)

Resizes itself to fit the stories. Works on WordPress custom HTML blocks, Ghost, Webflow, Squarespace code blocks and plain HTML.

Option 2: Plain iframe

For places that block scripts. The news list stays a fixed height and scrolls inside the frame.

Option 3: Link

For tools that take a web address and embed it for you, such as Notion's /embed block, Google Sites, Slack and most newsletter tools.

Good to know

  • Stories refresh by themselves every few minutes. Nothing to maintain.
  • Every headline opens the original publisher in a new tab.
  • The TV screen is 16:9 and fills whatever width you give it. Visitors can press the frame's fullscreen button on most sites.
  • Embedding only shows the public wire. Nothing from the signed in app is included.
